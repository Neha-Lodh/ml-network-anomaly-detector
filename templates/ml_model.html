How It Works

This project uses two complementary machine learning models:

  • Isolation Forest (unsupervised) - learns what "normal" traffic looks like and flags statistical outliers without needing labelled data.
  • Random Forest Classifier (supervised) - trained on labelled examples to output a confidence probability that a given traffic record is anomalous.

The two model outputs are combined into a single 0-100 risk score (60% Isolation Forest + 40% Random Forest), which is then mapped to a Low / Medium / High risk level. A simple rule-based explanation (e.g. "high failed connection count", "uncommon destination port") is generated for every flagged record so the result is easy to understand.

Features used

src_port, dst_port, protocol, duration, packet_count, bytes_transferred, failed_connections, and an engineered bytes_per_packet ratio.
